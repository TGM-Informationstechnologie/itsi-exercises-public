    Proxy und Geo Location

    Einführung

    Beim Surfen im Internet werden zahlreiche Informationen über den eigenen Rechner, den verwendeten Internetanschluss und den Standort preisgegeben. Eine zentrale Rolle spielen dabei die öffentliche IP-Adresse sowie verschiedene Geolocation-Dienste, die daraus geografische Informationen ableiten.

    Proxy-Server können die Sicherheit erhöhen, indem sie als Vermittler zwischen Client und Zielsystem agieren. Sie können Inhalte filtern, Zugriffe protokollieren, Malware blockieren oder den Zugriff auf bestimmte Internetdienste einschränken. Darüber hinaus können sie die sichtbare IP-Adresse verändern und dadurch Geoblocking oder standortabhängige Dienste beeinflussen.

    Geolocation-Dienste versuchen anhand von IP-Adressen den Standort eines Benutzers zu bestimmen. Diese Informationen werden unter anderem für Content-Anpassungen, Online-Werbung, Sicherheitsmechanismen und regionale Zugriffsbeschränkungen eingesetzt.

    In dieser Übung lernst du die technische Funktionsweise von Proxy-Servern kennen, untersuchst die Auswirkungen auf die sichtbare IP-Adresse und analysierst, welche Informationen über deine Internetverbindung öffentlich ermittelt werden können.

    Ziele

    • die Funktionsweise eines Proxy-Servers erklären
    • einen Proxy in einem Browser konfigurieren und testen
    • Unterschiede zwischen direkter Internetverbindung und Proxy-Nutzung nachvollziehen
    • Auswirkungen eines Proxys auf die öffentliche IP-Adresse analysieren
    • Geolocation-Dienste einsetzen und deren Ergebnisse bewerten
    • öffentlich verfügbare Informationen zu einer IP-Adresse recherchieren
    • Unterschiede zwischen Proxy, VPN und direkter Internetverbindung erklären
    • Datenschutz- und Sicherheitsrisiken im Zusammenhang mit Standortdaten beurteilen

    Kompetenzzuordnung

    Grundlagen der IT Sicherheit

    • Strategien zur Erhöhung der Privatsphäre im Internet entwickeln.

    Methoden und Verfahren der IT-Sicherheit

    • grundlegende Zugriffsschutzmechanismen erklären und einrichten;

    Voraussetzungen

    • Firefox oder Chrome installiert
    • (Optional) FoxyProxy-Extension installiert
    • Zugang zu einem öffentlichen oder lokalen Proxy-Server (z. B. über https://free-proxy-list.net oder einen eigenen lokalen Proxy wie Squid)

    Detaillierte Aufgabenbeschreibung

    Die Übung besteht aus einem praktischen Teil zur Verwendung eines Proxy-Servers sowie einer Analyse der öffentlich sichtbaren Informationen einer Internetverbindung.

    Aufgabe Grundkompetenz:

    Teil 1 – Proxy im Browser

    (Optional) FoxyProxy installieren

    1. Öffne Firefox oder Chrome.
    2. Installiere die Erweiterung FoxyProxy Standard.
    3. Überprüfe, ob das FoxyProxy-Symbol in der Symbolleiste erscheint.

    Proxy konfigurieren

    Hinweis: FoxyProxy ist nicht zwingend erforderlich. Die Proxy-Einstellungen können auch direkt im Browser oder über die Windows-Netzwerkeinstellungen vorgenommen werden. FoxyProxy erleichtert lediglich die Verwaltung mehrerer Proxy-Profile und das schnelle Umschalten zwischen verschiedenen Proxy-Servern.

    Variante A: Direkte Konfiguration im Browser

    Firefox

    Einstellungen → Allgemein → Netzwerk-Einstellungen → Einstellungen

    Wähle:

    Manuelle Proxy-Konfiguration

    Chrome / Edge

    Chrome und Edge verwenden die Proxy-Einstellungen von Windows, öffne:

    Einstellungen → Netzwerk und Internet → Proxy

    Aktiviere:

    Manuellen Proxyserver verwenden

    Variante B: Verwendung von FoxyProxy (optional)

    1. Öffne die Optionen von FoxyProxy.
    2. Erstelle einen neuen Proxy-Eintrag.

    3. Trage folgende Informationen ein:

    4. IP-Adresse

    5. Port
    6. optional Benutzername und Passwort

    Aktiviere den Proxy.

    • Proxy für alle Verbindungen oder
    • Proxy nur für bestimmte Webseiten

    Verbindungsweg dokumentieren

    Beschreibe den Kommunikationsweg:

    Ohne Proxy

    Browser → Webserver

    Mit Proxy

    Browser → Proxy-Server → Webserver

    Fragestellung

    • Welche Systeme sehen deine echte IP-Adresse?
    • Welche Systeme sehen nur die Proxy-IP-Adresse?
    • Welche Vor- und Nachteile ergeben sich daraus?

    Teil 2 – Öffentliche IP-Adresse untersuchen

    Direkte Verbindung

    Besuche:

    https://whatismyipaddress.com

    Dokumentiere:

    • öffentliche IP-Adresse
    • ermitteltes Land
    • Region
    • Stadt
    • Internetanbieter

    Verbindung über Proxy

    Aktiviere den Proxy.

    Besuche erneut: https://whatismyipaddress.com

    Dokumentiere erneut:

    • öffentliche IP-Adresse
    • Standort
    • Provider

    Vergleiche die Ergebnisse.

    Beantworte:

    • Welche Informationen haben sich verändert?
    • Welche Informationen sind gleich geblieben?
    • Warum wird eine andere IP-Adresse angezeigt?

    Teil 3 – Geoblocking demonstrieren

    1. Wähle einen Proxy aus einem anderen Land.
    2. Aktiviere diesen Proxy.
    3. Besuche eine Website mit regionalen Einschränkungen (z. B. YouTube-Videos oder Nachrichtenseiten)
    4. Beobachte, ob sich der Zugriff verändert

    Dokumentiere:

    Land IP-Adresse Veränderung
    Ohne Proxy
    Proxy 1
    Proxy 2

    Beantworte:

    • Wurde die Location korrekt erkannt?
    • Wie stark verändern sich die Ergebnisse zwischen verschiedenen Proxys?
    • Welche Dienste reagieren auf den geänderten Standort?

    Hinweis: Fehler "Sie können xyz . com nicht aufrufen, weil diese HSTS verwendet".

    • Gehe zu chrome://net-internals/#hsts und gib den Domainnamen bei Query (alles nach "https://") ein.
    • Wird er gefunden gib den selben Domainnamen bei Delete ein.
    • Lade die Seite neu, gehe auf Erweitert um zur Seite zu gelangen.

    Teil 6 – Geolocation mit PowerShell

    Du kannst mit PowerShell relativ einfach Informationen zur Geolokalisierung einer IP-Adresse abrufen, indem du öffentliche APIs nutzt.

    Finde mittels recherchierten verfügbaren APIs und Webseiten möglichst viel über deine aktuelle externe IP Adresse heraus.

    Hier erste Beispielaufrufe (es gibt aber noch viel mehr):

    Eigene öffentliche IP-Adresse ermitteln

    Invoke-RestMethod -Uri "https://api.ipify.org?format=json"

    Standortinformationen abrufen

    $ip = "8.8.8.8"
Invoke-RestMethod -Uri "http://ip-api.com/json/$ip"

    Eigene IP automatisch verwenden

    $myIP = (Invoke-RestMethod -Uri "https://api.ipify.org?format=json").ip
Invoke-RestMethod -Uri "http://ip-api.com/json/$myIP"
