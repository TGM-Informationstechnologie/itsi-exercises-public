    PiHole einrichten

    Einführung

    Werbung und Tracking sind heutzutage auf vielen Webseiten und in zahlreichen Apps integriert. Dabei werden oft Informationen über das Surfverhalten der Nutzerinnen und Nutzer gesammelt, um personalisierte Werbung anzuzeigen oder Nutzerprofile zu erstellen. Um die Privatsphäre besser zu schützen und unerwünschte Inhalte zu reduzieren, können sogenannte DNS-Filter eingesetzt werden.

    Eine bekannte Lösung dafür ist Pi-hole. Pi-hole arbeitet als DNS-Server und überprüft DNS-Anfragen auf bekannte Werbe- und Tracking-Domains. Werden solche Domains erkannt, blockiert Pi-hole die Anfrage, bevor eine Verbindung aufgebaut werden kann. Dadurch können Werbung, Tracker und teilweise auch schädliche Inhalte netzwerkweit gefiltert werden, ohne dass auf jedem Endgerät zusätzliche Software installiert werden muss.

    In dieser Übung wird Pi-hole mithilfe von Docker in einer virtuellen Maschine eingerichtet und konfiguriert. Anschließend wird der eigene Rechner so angepasst, dass er Pi-hole als DNS-Server verwendet. Dabei werden die Grundlagen von DNS, DNS-Filtering und Netzwerksicherheit praktisch angewendet. Zusätzlich werden mögliche Umgehungsmöglichkeiten wie alternative DNS-Server oder DNS-over-HTTPS betrachtet, um die Grenzen und Herausforderungen solcher Schutzmaßnahmen besser zu verstehen.

    Ziele

    • Pi-hole in einer virtuellen Maschine installieren
    • Ein virtuelles Netzwerk korrekt konfigurieren
    • Deinen Host so einstellen, dass er den Pi-hole als DNS verwendet
    • Grundlegende Funktionsweise von DNS-Filtern verstehen

    Detaillierte Aufgabenbeschreibung

    Aufgabe Grundkompetenz:

    Teil 1 - Pi-Hole innerhalb einer Virtuellen Maschine

    Setze Pi-Hole in einer VM auf deinem Rechner auf. Konfiguriere das virtuelle Netzwerkinterface entsprechend so, dass du von deinem Host die VM als DNS-Server verwenden kannst und konfiguriere den Host entsprechend

    Aufgabe1: Projekt vorbereiten

    Arbeitsverzeichnis erstellen: mkdir pihole-docker

    Wechsle anschließend in das Directory cd pihole-docker

    Erstelle ein Docker Compose yaml: nano docker-compose.yml

    Aufgabe 2: Pi-hole korrekt konfigurieren (Compose)

    Verwende folgende Vorlage (angepasst aus offizieller Doku: GitHub - pi-hole/docker-pi-hole):

    services:
  pihole:
    container_name: pihole
    image: pihole/pihole:latest

    ports:
    - "53:53/tcp"
    - "53:53/udp"
    - "80:80/tcp"
    - "443:443/tcp"

  environment:
    TZ: "Europe/Vienna"
    FTLCONF_webserver_api_password: "htl123"
    FTLCONF_dns_listeningMode: "ALL"

  volumes:
    - "./etc-pihole:/etc/pihole"

  restart: unless-stopped

    Wichtige Hinweise (aus offizieller Doku):

    • Port 53 (TCP + UDP) ist notwendig für DNS
    • Port 80 + 443 für Webinterface
    • Volumes speichern Konfiguration dauerhaft
    • dns_listeningMode=ALL, wenn Docker Bridge genutzt wird

    Aufgabe 3: Container starten und Status prüfen

    docker compose up -d
docker ps

    Aufgabe 4: Zugriff testen

    Im Browser:

    http://localhost/admin

    Login:

    • Passwort: htl123

    Dashboard sollte sichtbar sein.

    Aufgabe 5: DNS-Konfiguration am Host

    Dein Rechner nutzt Pi-hole als DNS

    Setze DNS auf: 127.0.0.1 oder <deine-IP-Adresse>

    Teste mittels: nslookup google.com

    Aufgabe 6: Funktion überprüfen

    1. Rufe Testseite auf: AdBlock Tester: test your AdBlock extensions
    2. Kontrolle im Pi-hole Dashboard:
    3. Queries sichtbar
    4. Geblockte Domains vorhanden

    Typische Fehler:

    • Port 53 bereits belegt (z.B. systemd-resolved)
    • Firewall blockiert DNS
